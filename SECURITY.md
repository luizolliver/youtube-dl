# Segurança

Se você encontrar uma falha de segurança no Vela Downloader, por exemplo algo que exponha os logins salvos ou permita executar código, não abra uma issue pública.

Use o botão **Report a vulnerability** na aba [Security](https://github.com/luizolliver/youtube-dl/security) do repositório para enviar o relato em particular. Inclua os passos para reproduzir e a versão do Vela.

Falhas no próprio yt-dlp devem ser relatadas ao [projeto yt-dlp](https://github.com/yt-dlp/yt-dlp/security).
